# Contributing

Reproducible bug reports and focused improvements are welcome.

## Report a problem

Use [Issues](https://github.com/Tyler-Keesee/Bully-Scholarship-Edition-PC-Fix/issues/new/choose). Include the preview version, supported game build, installed plugins, exact inputs, steps to reproduce, expected behavior, and what happened. Say whether Setup reported success and whether the game was fully restarted.

For combat problems, identify the object/weapon, melee and fire keys, and whether lock-on was held. For flashing, say whether the experimental render ASI was actually disabled and whether the problem occurs with the original renderer.

Remove personal information from logs. Do not attach private saves, account data, full game files, or third-party binaries.

## Propose a change

1. Read [known issues](KNOWN_ISSUES.md), [build notes](docs/BUILDING.md), and [third-party notices](THIRD_PARTY_NOTICES.md).
2. Keep the change focused and preserve executable/HUD compatibility checks, backups, later-edit protections, menu controls, and third-party credits.
3. Explain the triggering problem, resulting behavior, checks performed, and remaining limits.
4. Distinguish unit/self-test results from real gameplay observations. Do not claim full compatibility from one system.

Do not commit local saves, installation backups, logs containing personal paths, generated binaries, or original game assets. The experimental render V2 source must not be presented as a reproducible V1 release.
